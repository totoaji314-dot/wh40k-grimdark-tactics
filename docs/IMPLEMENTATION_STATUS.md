# 구현 현황 (2026-10-29)

저장소 `totoaji314-dot/wh40k-grimdark-tactics`, 브랜치 `main`. 공개 링크 https://totoaji314-dot.github.io/wh40k-grimdark-tactics/

## 구현 및 검증 완료
- **Space Marine (2011) 원본 모델 적용 (로컬 전용)**: 레안드로스·시도누스 원본 메시·텍스처·스킨 가중치 + SM1 볼터·체인소드를 게임 리그에 결합, 24개 애니메이션, GLB 변환, 개발 서버에서 전투 적용(이동·사격·근접·사망 확인). 공개 Pages에는 자체 제작 모델
- 4진영(마린 30·카디안 100·크리그 100·오크 100), 16개 병종 모델·리그·24개 애니메이션, 3단계 LOD, GPU 인스턴싱 스키닝
- **스페이스 마린 모델 재설계** (Mk VII 비례: 높은 견갑, 고르젯 속 헬멧, 아퀼라 흉갑, 리브 복부, 두꺼운 다리·부츠, 큰 백팩) — 인게임·Blender 렌더 확인
- 부대 명령: 이동·달리기·공격·돌격·정지·자유사격 on/off(실제 사격 중지 테스트 통과)·진형 4종·능력
- **드래그 진형 폭 → 열/행 수** (Total War식: 길게 끌면 얇고 넓게, 짧게 끌면 두껍게), 미리보기 마커가 실제 슬롯과 동일
- **전투 전 배치 단계**: 배치 구역 표시, 즉시 배치·회전·폭 지정, 공격 금지, 전투 시작 버튼/Enter
- **부대 그룹**: Ctrl+1~9 지정, 숫자로 선택, 두 번 누르면 카메라 이동 (그룹이 없는 1~4는 기존처럼 진형, Alt+1~4는 항상 진형)
- **집단 근접전**: 수비자당 동시 공격 상한(체격별), 덜 붐비는 적 선택, 측면으로 벌려 접근, 꽉 찬 적 앞에서는 대기, 첫 타격 시차, 참호 수비 유지·근접 미교전 병사의 참호 사격
- 병사 AI(표적·사선·엄폐·재장전·사기·제압·패주), 지휘관 AI(오크 돌격·제국 사격·역돌격·방어 진형)
- 해 질 녘 고딕 도시 전장, 원경 하이브, 폐허 외곽, 연기·불·섬광
- 3–4초 셰이더 재컴파일 멈춤 수정
- PC·휴대폰 터치 조작, GitHub Actions → gh-pages 자동 배포
