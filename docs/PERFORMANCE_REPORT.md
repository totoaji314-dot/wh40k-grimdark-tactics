# 성능 측정 (2026-10-31 갱신)

## 홀리 테라 황궁 재구축 (2026-10-31 오후) — 측정함
장치: 개발 PC (RTX 4060 Laptop GPU, Chrome 헤드리스 + 실제 GPU, ANGLE D3D11). 이번에는 Total War: Attila가 꺼져 있었다.
측정 방법: `tools/shoot.mjs`로 홀리 테라 자동 전투(`?auto=…&map=terra`)를 띄우고 정문이 보이는 시점에서 평균 FPS·프레임 시간 p95·`renderer.info` 기록. 황궁 끄기는 같은 장면에서 `palace.group.visible = false`.

| 경우 | FPS | 프레임 p95 | 그리기 호출 | 삼각형 |
|---|---|---|---|---|
| 개발 서버, 높음, 정문 시점, 황궁 켬 | 129.9 | 9.9 ms | 375 | 278만 |
| 같은 장면, 황궁 끔 | 129.4 | — | 202 | 249만 |
| 전투 중반 (93 대 71 생존), 황궁 켬 | 129.8 | — | 320 | — |
| 배포용 빌드, 높음 | 129.9 / 129.4 (두 시점) | — | 369 / 314 | — |
| 배포용 빌드, 낮음 | 129.6 | — | 158 / 131 | — |
| 휴대폰 흉내 (915×412, DPR 2.6), 낮음, CPU 4배 감속, 황궁 켬 | 88.4 | 20.1 ms | 164 | — |
| 같은 조건, 황궁 끔 | 99.2 | — | 93 | — |

읽는 법:
- 헤드리스 Chrome은 약 130 FPS에서 멈추므로 PC 결과는 "상한에 닿음"이다. 황궁이 GPU에 주는 부담을 이 숫자로 구분할 수는 없다.
- 휴대폰 흉내는 CPU만 4배 느리게 했고 GPU는 데스크톱 그대로다. **실제 휴대폰 GPU 성능이 아니다.** 이 조건에서 황궁은 FPS를 약 11% 낮췄다(99.2 → 88.4), 그리기 호출 +71.
- 황궁의 그리기 호출을 줄이는 장치: 조각×LOD×재질마다 인스턴스 메시 1개, 거리별 LOD(정문 301 m / 735 m, 1.5 m 미만 소품 40 m / 110 m), 원경 첨탑·작은 소품은 그림자 안 드리움.
- 다운로드: `palace.glb` 11.2 MB는 홀리 테라를 고를 때만 받는다. 홀리 테라 가로등·탐조등 파일은 3.1 MB → 0.19 MB로 줄었다.

## 홀리 테라 전장 (2026-10-31) — 유효한 FPS 측정 못 함
- 황궁 세트: 메시 20개, 인스턴스 174개, 삼각형 28.1만 (전장 전체). 추가 다운로드 3.1 MB는 홀리 테라에서만.
- 기본 소품 파일은 1.8 → 0.9 MB로 줄어 다른 전장의 로딩이 가벼워짐.
- 측정 시점에 다시 **Total War: Attila가 실행 중 (GPU 56%)**이라 FPS를 재지 않았다.

## 외부 소품 추가 후 (2026-10-30 밤) — 유효한 FPS 측정 못 함
- 소품: 대 와아아그 기준 245개 배치, 인스턴스 메시 18개(그리기 호출 18회 + 그림자), 삼각형 162k.
- 측정 시도 중 같은 PC에서 **Total War: Attila가 실행 중이라 GPU 사용률 99%** (nvidia-smi: P0, 79 °C, 85 W). 이 상태에서는 소품을 꺼도(`?noprops`) 12–14 FPS, 켜도 11–16 FPS로, 지난 측정(127 FPS)과 비교할 수 없다. 같은 세션에서 켜고 끄기를 번갈아 해도 일관된 차이는 없었다.
- 다른 GPU 작업이 없을 때 다시 측정해야 한다.

장치: 개발 PC (RTX 4060 Laptop, Chrome, ANGLE D3D11), 1600×900, 빌드 결과물(`dist`)을 Pages와 같은 하위 경로로 로컬 서빙.
측정 방법: `tools/shoot.mjs`로 Chrome 구동, 게임 루프 프레임 함수의 CPU 시간 측정(2.5초 구간별 95퍼센타일), `fpsAcc` 평균 FPS.

## 이번에 고친 성능 문제
- **전투 중 3–4초 멈춤**: 폭발·총구 섬광용 점광원을 `visible` 토글 → 광원 수 변경 → three.js가 모든 조명 셰이더 재컴파일. 광원을 항상 보이게 두고 강도만 0으로 바꾸도록 수정(`src/render/Effects.ts`). 수정 전 2.5초 구간 p95 프레임 3,151–4,001 ms → 수정 후 2–4 ms. 섬광은 제거하지 않았다.
- 연기 파티클이 풀(1,170개)을 가득 채워 전투 연기가 생성되지 않던 문제: 배경 화재·굴뚝은 풀의 65%까지만.

## 측정하지 못한 것
- 실제 디벗(크롬북/안드로이드) GPU, 1% Low FPS, GPU 메모리, JS 힙, 초기 로딩 시간(라이브 PC 1회 15.7초 측정).
